#Auth Sample for storing Creds in DB 
User H2 DB for sample
We encrypt the password using BCryptPasswordEncoder
Creds are created using register API.
For this we disable security for the register API endpoint.







The default redirect URI template is {baseUrl}/login/oauth2/code/{registrationId}. 
The registrationId is a unique identifier for the ClientRegistration.
